# Comprehensive Test Scenarios for YouTube Website

## 1. Homepage Functionality

### Test Case ID: HP-001
**Test Title:** Verify Homepage Loading  
**Preconditions:** Internet connection is available  
**Steps to Reproduce:**
1. Open a browser (Chrome, Firefox, Edge, Safari)
2. Navigate to youtube.com
3. Observe the homepage loading

**Expected Result:** YouTube homepage loads completely with all elements visible including header, sidebar, and recommended videos section  
**Priority:** High

### Test Case ID: HP-002
**Test Title:** Verify Recommended Videos Display  
**Preconditions:** User is on YouTube homepage  
**Steps to Reproduce:**
1. Observe the recommended videos section on the homepage
2. Scroll down to load more recommended videos

**Expected Result:** Multiple video thumbnails with titles, channel names, view counts, and upload times are displayed  
**Priority:** High

### Test Case ID: HP-003
**Test Title:** Verify Trending Section  
**Preconditions:** User is on YouTube homepage  
**Steps to Reproduce:**
1. Locate and click on the "Trending" or "Explore" section in the sidebar
2. Observe the trending videos displayed

**Expected Result:** Trending videos are displayed with appropriate thumbnails, titles, and metrics  
**Priority:** Medium

### Test Case ID: HP-004
**Test Title:** Verify Shorts Section  
**Preconditions:** User is on YouTube homepage  
**Steps to Reproduce:**
1. Locate the "Shorts" section on the homepage
2. Click on a Short video

**Expected Result:** Short video begins playing in a vertical format with appropriate controls  
**Priority:** Medium

### Test Case ID: HP-005
**Test Title:** Verify Homepage Responsiveness  
**Preconditions:** Access to multiple devices or browser resizing capability  
**Steps to Reproduce:**
1. Access YouTube homepage on desktop browser
2. Resize browser window to different dimensions
3. Access YouTube homepage on tablet device
4. Access YouTube homepage on mobile device

**Expected Result:** Homepage layout adjusts appropriately for each screen size with all key elements remaining accessible  
**Priority:** High

## 2. Search Functionality

### Test Case ID: SF-001
**Test Title:** Search for Videos by Keyword  
**Preconditions:** User is on YouTube homepage  
**Steps to Reproduce:**
1. Click on the search bar
2. Type a keyword (e.g., "cooking tutorial")
3. Press Enter or click the search icon

**Expected Result:** Search results page displays with videos related to the search keyword  
**Priority:** High

### Test Case ID: SF-002
**Test Title:** Filter Search Results  
**Preconditions:** User has performed a search and is on the search results page  
**Steps to Reproduce:**
1. Click on the "Filter" button
2. Select different filter options:
   - Upload date (Last hour, Today, This week, This month, This year)
   - Type (Video, Channel, Playlist, Movie)
   - Duration (Under 4 minutes, 4-20 minutes, Over 20 minutes)
   - Features (Live, 4K, HD, Subtitles/CC, Creative Commons, 360°, VR180, 3D, HDR, Location, Purchased)

**Expected Result:** Search results update according to the selected filters  
**Priority:** Medium

### Test Case ID: SF-003
**Test Title:** Verify Autocomplete Suggestions  
**Preconditions:** User is on YouTube homepage  
**Steps to Reproduce:**
1. Click on the search bar
2. Slowly type a partial search term (e.g., "how to")
3. Pause typing and observe

**Expected Result:** Dropdown appears with autocomplete suggestions related to the partial search term  
**Priority:** Medium

### Test Case ID: SF-004
**Test Title:** Handle Empty Search Query  
**Preconditions:** User is on YouTube homepage  
**Steps to Reproduce:**
1. Click on the search bar
2. Press Enter without typing anything

**Expected Result:** No search is performed, user remains on the current page  
**Priority:** Low

### Test Case ID: SF-005
**Test Title:** Handle Invalid Search Query  
**Preconditions:** User is on YouTube homepage  
**Steps to Reproduce:**
1. Click on the search bar
2. Type random characters (e.g., "xyzabc123!@#")
3. Press Enter

**Expected Result:** Search results page shows "No results found" message or suggests alternative searches  
**Priority:** Low

3. Press ESC key to exit full-screen

**Preconditions:** User is watching a video  
**Steps to Reproduce:**

### Test Case ID: VP-006
**Test Title:** Enable Mini-player  
**Preconditions:** User is watching a video  
**Steps to Reproduce:**
1. Click on the mini-player icon in the video player
2. Navigate to another page on YouTube

**Expected Result:** Video continues playing in a small floating window that can be repositioned  
**Priority:** Medium

### Test Case ID: VP-007
**Test Title:** Handle Video Buffering  
**Preconditions:** User is watching a video with potentially unstable internet connection  
**Steps to Reproduce:**
1. Start playing a video
2. Temporarily limit network bandwidth or disconnect internet briefly
3. Restore connection

**Expected Result:** Video shows buffering indicator when connection is limited and resumes playback when connection is restored

## 10. Accessibility and Error Handling

### Test Case ID: AE-001
**Test Title:** Test Keyboard Navigation  
**Preconditions:** Desktop browser with keyboard  
**Steps to Reproduce:**
1. Open YouTube in a browser
2. Navigate through the interface using only Tab, Shift+Tab, Enter, and arrow keys
3. Attempt to:
   - Navigate to a video
   - Play/pause a video
   - Adjust volume
   - Access menus

**Expected Result:** All key functionality is accessible via keyboard navigation  
**Priority:** Medium

### Test Case ID: AE-002
**Test Title:** Test Video Playback Accessibility Controls  
**Preconditions:** User is watching a video  
**Steps to Reproduce:**
1. Use keyboard shortcuts for video control:
   - Space bar for play/pause
   - K for play/pause
   - J for rewind
   - L for fast forward
   - M for mute/unmute
   - Up/down arrows for volume
   - Left/right arrows for seeking

**Expected Result:** Keyboard shortcuts function correctly for video playback control  
**Priority:** Medium

### Test Case ID: AE-003
**Test Title:** Verify Error Message for Non-existent Video  
**Preconditions:** None  
**Steps to Reproduce:**
1. Attempt to access a non-existent video URL (e.g., youtube.com/watch?v=nonexistentvideoid)

**Expected Result:** Appropriate error message displayed indicating the video is unavailable  
**Priority:** Medium

### Test Case ID: AE-004
**Test Title:** Verify Error Message for Failed Upload
