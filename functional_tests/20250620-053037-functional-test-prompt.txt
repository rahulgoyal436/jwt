1. Click on the search bar

**Priority:** High

### Test Case ID: SF-002
**Test Title:** Search Results Filtering  
**Preconditions:** User has performed a search  
**Steps to Reproduce:**
1. On the search results page, click on the "Filters" button
2. Select different filter options (Upload date, Type, Duration, Features)
3. Observe the filtered results

**Expected Result:** Search results update according to the selected filters  
**Priority:** High

### Test Case ID: SF-003
**Test Title:** Search Autocomplete Functionality  
**Preconditions:** User is on YouTube homepage  
**Steps to Reproduce:**
1. Click on the search bar
2. Slowly type a partial search term (e.g., "how to")
3. Pause typing and observe

**Expected Result:** Autocomplete suggestions appear below the search bar with relevant search terms  
**Priority:** Medium

### Test Case ID: SF-004
**Test Title:** Empty Search Query Handling  
**Preconditions:** User is on YouTube homepage  
**Steps to Reproduce:**
1. Click on the search bar
2. Without typing anything, press Enter or click the search icon

**Expected Result:** No search is performed, user remains on the current page  
**Priority:** Low

### Test Case ID: SF-005
**Test Title:** Special Characters Search  
**Preconditions:** User is on YouTube homepage  
**Steps to Reproduce:**
1. Click on the search bar
2. Enter special characters (e.g., "#$%^&*")
3. Press Enter or click the search icon

**Expected Result:** System handles special characters appropriately, either showing relevant results or a "no results found" message  
**Priority:** Low
